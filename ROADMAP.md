# Roadmap

**Now:** V2 is here. It answers "is everything OK?" with no AI, protects important data by itself, and checks production after your AI ships a fix.

**Next:**
- A separate autonomous agent, Seven: tool routing, run limits and budgets, log-safe mode.
- Tuning the Call Inspector on real traffic.
- A signed image and a one-line install.

**Later:**
- Scoped server access, with an allow-list checked on the server.
- MySQL detail in the Call Inspector.

**Not planned:** a hosted Unit7 that holds your root keys, our own coding agent, our own AI model, a Kubernetes layer, a template catalogue. See why in [LIMITS.md](LIMITS.md).
